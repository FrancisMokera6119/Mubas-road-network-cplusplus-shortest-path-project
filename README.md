PROECT DESCRIPTION
This project is a C++ program designed to find the shortest path between two locations in a MUBAS campus which is weighted. The user enters a source location and a destination location using letters A to T. The program calculates and display shortest path and its total distance.
PROGRAMMING LANGAUGE
C++
HOW TO RUN THE PROGRAM
1. Open the online compiler link provided below
2. click run
3. enter the source and destination letters (A TO T).
4. View the shortest path and total distance
